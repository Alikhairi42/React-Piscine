## 📅 Curriculum & Resources

### 🟢 Day 00: Components & Props (Static UI)
**Objective:** Understand React's component-based architecture and how to pass data dynamically.
* **Project:** `Student Directory` - Build modular user cards, pass data via props, and render lists using `.map()`.
* **📚 Professional Resources:**
  * [React Docs: Describing the UI](https://react.dev/learn/describing-the-ui)
  * [React Docs: Passing Props to a Component](https://react.dev/learn/passing-props-to-a-component)
  * [React Docs: Rendering Lists](https://react.dev/learn/rendering-lists)

### 🔵 Day 01: State & Events (Dynamic UI)
**Objective:** Bring components to life by managing local state and handling user interactions.
* **Project:** `Task Manager` - Create an interactive To-Do list with add/delete functionality and real-time input tracking.
* **📚 Professional Resources:**
  * [React Docs: State - A Component's Memory](https://react.dev/learn/state-a-components-memory)
  * [React Docs: Responding to Events](https://react.dev/learn/responding-to-events)
  * [React Docs: Updating Arrays in State](https://react.dev/learn/updating-arrays-in-state)

### 🟣 Day 02: Side Effects & Data Fetching (APIs)
**Objective:** Connect your application to the outside world and manage component lifecycles.
* **Project:** `API Explorer` - Fetch data from a public REST API upon component mount and implement a local search filter.
* **📚 Professional Resources:**
  * [React Docs: Synchronizing with Effects](https://react.dev/learn/synchronizing-with-effects)
  * [MDN Web Docs: Using the Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)
  * [Article: A Complete Guide to useEffect](https://overreacted.io/a-complete-guide-to-useeffect/)

### 🔴 Day 03: Routing & SPA Architecture
**Objective:** Implement client-side routing to navigate between different views seamlessly.
* **Project:** `Multi-Page App` - Integrate `react-router-dom` to connect previous days' work into a cohesive SPA, featuring dynamic routes (e.g., `/user/:id`).
* **📚 Professional Resources:**
  * [React Router Official Tutorial](https://reactrouter.com/en/main/start/tutorial)
  * [Video: React Router v6 in 20 Minutes](https://www.youtube.com/watch?v=SMHOcgjcZ_w)
